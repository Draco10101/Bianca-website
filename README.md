# Bianca Design & Marketing website

Live site: https://draco10101.github.io/Bianca-website/

A static website for Bianca Design & Marketing. The current site source and visual assets are kept at the repository root and in the existing `images/` directory.

## Current file layout

```text
.
├── index.html
├── images/
│   └── bianca-promo.jpg
├── Bianca Web Ads
├── Bianca-Website-Hosting.zip
└── README.txt
```

- `index.html` is the GitHub Pages entry point.
- `images/bianca-promo.jpg` is the promotional image used by the page.
- `Bianca Web Ads` is the shareable advertising copy.
- `Bianca-Website-Hosting.zip` is retained as an archive/backup. Do not remove it as part of routine cleanup.
- `README.txt` is retained as an earlier project note; this README is the current guide.

## Local preview

Keep the directory structure unchanged, then open `index.html` in a browser or a mobile editor such as Acode. Check the navigation links, image loading, and WhatsApp contact links.

## GitHub Pages

The repository is already configured for GitHub Pages from the `main` branch. The published site is:

https://draco10101.github.io/Bianca-website/

Keep `index.html` at the repository root and preserve the `images/` path unless the HTML references are updated in the same change.

## Safe maintenance checklist

1. Make changes on a feature or maintenance branch.
2. Preview the page locally before publishing.
3. Check that all image paths and contact links work.
4. Open a pull request and review the diff before merging.
5. Keep the ZIP archive and recovered source backups until a separate verified backup exists.

## Contact

The current website's WhatsApp contact link is configured for the business number displayed on the website. Verify contact details before changing them.
