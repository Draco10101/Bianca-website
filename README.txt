FREE HOSTING WITH GITHUB PAGES
1. Sign in at https://github.com/ and create a NEW PUBLIC repository named bianca-website (public is needed for GitHub Pages on many free setups; do not upload private data).
2. Upload index.html and the images folder with bianca-promo.jpg. Preserve the folder name and path exactly.
3. In the repository, open Settings → Pages.
4. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
5. Wait for GitHub Pages to publish; its URL will appear on the Pages settings screen.
